# Проверка Cloudflare Pages и продакшен-домена nlping.ru

Ты — браузерный агент-наблюдатель. Нужно провести финальные ручные проверки деплоя статического зеркала nlping.ru, доступного через Cloudflare Pages. Работай только через браузер и публичные веб-инструменты, без авторизаций и без изменений в репозитории.

## Цель
Подтвердить, что все ключевые страницы на доменах `https://248c2942.nlping.pages.dev` и `https://nlping.ru` корректно отдаются в UTF-8, отображаются без артефактов и отдают ожидаемые заголовки.

## Список URL для просмотра в браузере
Для каждого домена открой и оцени следующие страницы:

1. `/` (главная страница)
2. `/blog.html`
3. `/training10k.html`
4. `/webinar.nlping.ru/index.html`
5. `/w.nlping.ru/index.html`

В итоге получится 10 проверок (5 страниц × 2 домена).

## Что проверить на каждой странице
- **Отображение текста:** нет кракозябр, весь русский и латинский текст читаем.
- **Картинки и стили:** ключевые изображения и оформление загружаются.
- **View Source:** в `<head>` явно указан `<meta charset="utf-8">`.
- **Дата и заметки:** запиши момент проверки (UTC) и любые отличия от ожиданий.

## Проверка HTTP-заголовков
- Для каждого из 10 URL получи HTTP-заголовки ответа с помощью публичного инструмента (например, https://httpstatus.io/ или https://www.webconfs.com/http-header-check.php).
- Убедись, что `Content-Type` содержит `charset=utf-8`.
- Зафиксируй полный набор заголовков, дату и ссылку на использованный сервис.

## Дополнительно
- Если найдёшь расхождения (битые картинки, неверный `charset`, ошибки 4xx/5xx), приложи скриншоты/ссылки на подтверждение.
- Скриншоты можно сделать через любой общедоступный сервис без регистрации (например, https://snipboard.io/). Приложи ссылки.
